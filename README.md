# ことのは単語 Web版 v1.2

古文単語を選択問題・記述問題で学習できるWebアプリです。収録単語数は **315語**。ログインなしでも基本的な学習を始められます。
収録している単語は、桐原書店　読んで見て聞いて覚える　重要古文単語315 四訂版を元に作成されております。Dashcloudlyが開発および運営をする非公式サイトであり、桐原書店株式会社とは一切関係ありません。内容に関しては一切の保証がありませんので、正確性をお求めの場合は、実際の書物をご確認ください。

公開サイト
：[kobun.dashcloudly.com](https://kobun.dashcloudly.com/)

## 主な機能

- 開始・終了番号から全単語の範囲を選択。無効な範囲はエラーを表示し、入力途中の数字は自動で書き換えません。
- 古文単語→現代語訳、現代語訳→古文単語の6択と、現代語訳→古文単語の記述問題。
- 正誤・復習対象・進捗の表示、ブックマーク、単語検索。正誤は各単語の直近の解答結果で更新されます。
- 範囲をURLで共有（例：`/?view=words&start=1&end=50`）。
- Google、メール／パスワード、学校ID・クラスIDによるログイン。学校側で範囲を設定すると、その範囲への学習ショートカットを表示します。
- 復習と検索をまとめた一覧、PWAインストール、取得済みデータを使ったオフライン利用。

一部の機能はFirebase認証、学校側の登録、またはネットワーク接続が必要です。Firebaseを利用できない場合も、基本的な学習は続けられます。

## ローカルで確認する

ビルドツールは不要です。このリポジトリのルートで静的ファイルサーバーを起動してください。

```bash
python -m http.server 8000
```

ブラウザーで `http://localhost:8000/` を開きます。HTMLファイルを直接開く `file://` 方式では、Service Workerなどが正常に動作しません。Firebase認証を使う場合は、Firebase Console の Authentication で利用するドメインを許可してください。

## Firebaseを利用する場合

`assets/js/app.js` にWeb用Firebase設定と管理者判定の設定があります。別のFirebaseプロジェクトで利用する場合は、自分のプロジェクトに合わせて変更してください。この配布版は既存プロジェクト向けの設定を含むため、設定を変更せずにテストすると既存環境へ接続します。

1. Firebase Console でWebアプリを登録し、Authentication の使用するログイン方法（Google、メール／パスワード、学校ID利用時に必要な匿名認証）と承認済みドメインを確認します。
2. Firestoreを用意し、`firestore.rules` の内容を**対象プロジェクトを確認してから**適用します。学校IDやクラス、学校別テスト範囲は管理者による登録が必要です。

このリポジトリの `firebase.json` でFirestoreルールを配置できます。対象プロジェクトを指定して `firebase deploy --only firestore:rules --project <PROJECT_ID>` を実行してください。静的サイトの配信先は別途設定します。メールログインはCloud Functionsのメール照会を使わず、メール入力後にパスワード画面へ進みます。

## GitHubで公開する前に

- 収録する単語・訳語や画像など、**公開するデータの権利・利用条件**を確認してください。リポジトリに `LICENSE` は含まれておらず、公開だけでは第三者への再利用許諾を意味しません。
- `assets/js/app.js` と `firestore.rules` に既存環境の設定や管理者識別情報が含まれます。公開先に合った値とFirestoreルールを確認し、サービスアカウント鍵・秘密鍵・個人の学習データはコミットしないでください。
- GitHubへのプッシュだけではWebサイトは更新されません。公開サイトへのデプロイは、使用するHostingの設定と手順に従って別途行ってください。

## 更新とデータ保存

学習履歴・ブックマークは端末に保存されます。ログイン利用時にはFirebaseとの同期機能があります。PWAのキャッシュは `sw.js` のバージョンで管理しています。ファイルを変更して再公開するときは、必要に応じてHTML内のCSS／JSのバージョン指定とService Workerのキャッシュバージョンも更新してください。

## 注意

- FirestoreやFirebase認証が利用できない場合、ランキング・学校関連機能・端末間同期などは利用できません。
- 学習日数の連続記録機能は含みません。
## 最近の修正と確認

学校参加画面の見出しID、同期前のクラウド復元、プロフィール画像と学校ロゴの分離、ヘッダー寸法とスマートフォンの操作領域を修正しました。設定画面から学校管理と使い方を開けます。Firestoreの管理者判定では検証済みメールを必須とし、先生の学校変更を制限しています。ルールはWebファイルと別に配置してください。

表示用アイコンを128px WebP、PWAアイコンを192px/512px PNGに分けました。学習・先生・管理者ページのスクリプトはdeferで順序を保って読み込みます。

Node.jsで次の回帰チェックを実行できます（外部通信なし、Firebaseを模擬）。Firestoreルールのエミュレーター検証を代替するものではありません。

```bash
node tests/login-regression.cjs
node tests/sync-regression.cjs
node --check assets/js/app.js
node --check sw.js
```
