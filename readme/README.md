# 古文単語マスター 分割版

- `ads.txt` はルート `/ads.txt` に配置しています。
- CSS/JS/アイコンは `assets/` 以下に分割しています。
- 単語テスト設定をスマホ向けに再設計しました。
  - 出題項目はプルダウン形式
  - 出題対象もプルダウン形式
  - 単語範囲は開始/終了番号を−/＋ボタンで調整可能
  - 選択・開閉・数値変更にアニメーションを追加
- 初回起動時に短い利用確認ポップアップを表示し、Googleログインまたはゲスト開始を選べます。

- 2026-05-04: 出題対象「すべて」を「○＋×」と同じ抽出条件に修正しました。


## 追加変更
- 新機能追加時のお知らせポップアップを追加しました。
- 未読のお知らせがある場合、右下のベルにバッジが表示されます。
- 一度確認すると、同じバージョンのお知らせは自動表示されません。
