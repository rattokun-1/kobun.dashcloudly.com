# 利用停止・先生ページ・管理者ページ分離

## 追加ページ
- `admin.html`：管理者専用ページ
- `teacher.html`：先生専用ページ

## 利用停止
管理者ページのユーザー管理で「利用停止」を有効にすると、該当ユーザーがログインした際に以下の文言を表示してアプリを使えない状態にします。

> 現在、このアカウントは管理者によって、利用停止の状態にさせられています。管理者までお問い合わせください。

## ロール
管理者ページでユーザーのロールを `teacher` にすると、`teacher.html` にアクセスできます。

## 管理者
管理者メールは以下で設定済みです。

```js
const ADMIN_EMAILS = [
  'yuki.1092.mkupo1216.m@gmail.com'
];
```

## Firebaseルール
`firestore.rules` を Firebase Console の Firestore ルールに貼り付けて公開してください。
管理者のみ以下を変更できます。

- アプリ設定 / メンテナンス設定
- 学校コード発行・停止・削除
- ユーザーの `role`
- ユーザーの `disabledInApp`
- 管理メモ

先生はユーザー情報・ランキングを閲覧できますが、設定変更はできません。
