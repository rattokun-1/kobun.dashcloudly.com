# 学校IDで学習する（v1.6）

## 学校管理者が行うこと

1. アカウント設定から「学校別参加コード」の学校IDを発行します。既存の発行済みコードも使用できます。
2. 「今回の単語テスト範囲」の学校ID・開始番号・終了番号を入力して保存します。クラスごとに範囲を変える場合のみ、クラスIDとクラス名も入力します。
3. 学校ID、必要ならクラスIDも生徒に伝えます。学校IDのみで参加した生徒には学校全体の範囲、クラスIDも入力した生徒にはそのクラスの範囲が表示されます。
4. クラスIDでログインを使う場合は `firestore.rules` の新しいクラスの読み取りルールをFirebaseに反映します。学校IDのみなら既存の `schoolCodes` 読み取りを利用します。

Firebase Authenticationで「匿名」を有効にすれば、この端末用の匿名アカウントでも進捗を同期できます。匿名認証が使えない場合は、学校IDを確認した後に端末内へ学習データを保存して利用できます。学校ID・クラスIDだけでは個人を識別できず、他端末への個人履歴の引き継ぎはできません。個人ごとの引き継ぎにはGoogleなどのアカウントを使用してください。

学校IDやクラスIDが未登録・停止中の場合は画面に理由が残ります。初回のID確認には通信が必要です。テスト範囲が未設定でも学校IDで参加できますが、範囲が保存されるまで「この範囲で学習する」ボタンは表示されません。
